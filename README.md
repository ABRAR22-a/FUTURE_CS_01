# FUTURE_CS_01

## Vulnerability Assessment Report

This repository contains the first task completed during the Future Interns Cyber Security Internship.

### Objective
Perform a read-only vulnerability assessment of a public website by identifying visible security controls, reviewing exposed services, and documenting potential security risks without exploiting the target.

### Tools Used
- Burp Suite Community Edition
- Browser Developer Tools

### Deliverables
- Vulnerability Assessment Report (PDF)

### Scope
- Read-only assessment
- No exploitation
- No brute force or denial-of-service testing

---

Created as part of the **Future Interns Cyber Security Internship Program**.
